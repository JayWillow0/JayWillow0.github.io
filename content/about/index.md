LiuYang，储能磷酸铁锂电池领域的电化学与算法工程师，主要从事电池电化学与热行为、寿命预测、机器学习算法、Vibe Coding 及科研软件工程化相关工作。

## 学术经历

- 博士阶段研究方向：质子交换膜燃料电池冷启动多物理场建模与多孔介质设计优化

## 研究方向

- 储能磷酸铁锂电池电化学与热行为
- 电化学与热仿真、参数标定
- 电池寿命预测、机器学习与深度学习
- Vibe Coding 与 Coding Agent 工程实践
- 科研算法的工程化与可复现实现
