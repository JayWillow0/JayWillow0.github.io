# 视觉系统

## 设计命题

站点是“学术期刊陈列室”，不是通用科技公司首页。结构来自研究论文、实验记录和多物理场图谱；装饰只在能够表达电化学、传递过程或数据关系时出现。

## Token

- Paper `#F3F6F8`：主背景。
- Ink `#17212B`：正文与高对比标题。
- Graphite `#5A6672`：说明文字和辅助线。
- Engineering Blue `#28536B`：主要交互色。
- Copper `#B65C32`：能量、警示和关键结果。
- Field Cyan `#3B88A8`：场分布、链接和次要数据。

标题使用中文宋体栈，正文使用系统中文无衬线字体栈，参数和代码使用 IBM Plex Mono 优先的等宽字体栈。

## 动效和无障碍

唯一环境动效是首页电池剖面图中的缓慢扫描线。所有交互必须显示键盘焦点；系统要求减少动画时，扫描线和卡片位移动画全部关闭。
